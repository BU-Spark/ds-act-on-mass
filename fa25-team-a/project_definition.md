# Act on MASS Team A Project Definitions

## Project Definition in Our Own Words

The Act on MASS project is a three part project consisting of the following phases:

1) Data collection - The team will develop a pipeline to collect PDF documents via web scraping that contain Massachusetts House and Senate member's voting records on bills and issues.
2) Relational Database Design - Scraped data will be stored in relational tables that will allow us to integrate them into Looker Studio. The relational design of the tables is critical to allow us to answer questions posed by the client such as "How does each legislator vote?", "How are roll call numbers linked to specific bills and amendments?" and more.
3) Visualization - We will take our cleaned and organized data into Looker Studio per the request of the client and create visualizations that can be used by a non-technical audience to receive answers to at minimum the 5 questions in the overview document. If time allows and research indicates more interesting patterns, those can be added.

Through these 3 steps we aim to provide Scotia and the Act on MASS team with a professional level visualization tool and a pipeline for continued data input into the tool to aid in their research of local politicians and their voting habits, especially in regard to specific issues and bills.

## Intended Datasets

From client/project description:

- Using API [https://malegislature.gov/api/swagger/index.html?url=/api/swagger/v1/swagger.json#/] to pull roll calls and other documents
- House journals [https://malegislature.gov/Journal/House/193]
- Senate journals [https://malegislature.gov/Journal/Senate/193]

## Project Objectives (as of 9/23/2025)

From client/project description:

- Create cleaned & structured dataset including: roll call voters, bill names, roll call numbers, amendments, and legislator voting records.
- Create interactive visualizations
- Answer client questions:
  - How does each legislator vote?
  - How many votes do legislators miss, and how often?
  - What trends exist in roll call voting over time?
  - How are roll call numbers linked to specific bills and amendments?
  - What patterns emerge across different legislative sessions?
